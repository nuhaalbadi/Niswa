# Niswa Dataset Code

This repository contains the code used to construct and process the Niswa dataset, a longitudinal dataset of Arabic Twitter discourse concerning women in Saudi Arabia. The dataset covers five study periods between 2011 and 2021 and includes a manually annotated benchmark for stance and multi-label topic classification.

The repository accompanies the dataset descriptor and provides the code used for data collection, geographic filtering, preprocessing and cleaning, annotation sampling, and dataset preparation. 


## Data Availability

The Niswa dataset is published and publicly available through Harvard Dataverse:
